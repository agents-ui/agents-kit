# Agent Form Generator

Watch AI dynamically generate form fields based on context with a live preview that updates as the agent builds the form.

## Features

- **Dynamic Fields**: AI adds, removes, and reorders fields in real time as it understands the requirements
- **Live Preview**: Side-by-side preview that renders the form as the agent constructs it
- **Validation Rules**: Auto-generated validation constraints for each field type
- **Field Types**: Support for text, number, select, checkbox, date, file upload, and custom inputs
- **Schema Export**: Export the finished form as JSON Schema or code for direct integration
