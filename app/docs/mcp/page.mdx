# Model Context Protocol

Use the standard [shadcn MCP server](https://ui.shadcn.com/docs/mcp) to let a coding assistant search and inspect Agents Kit components. It uses the same registry as the CLI. Agents Kit does not run a separate MCP server.

## Configure the registry

First follow [Installation](/docs/installation) to initialize shadcn in your application. Merge this namespace into the `registries` object in the application's `components.json`, keeping its other settings:

```json
{
  "registries": {
    "@agents-kit": "https://agents-ui.github.io/agents-kit/c/{name}.json"
  }
}
```

The server reads `components.json` from the application workspace. Open that folder in your coding assistant so it can discover the registry.

## Configure your client

For Cursor, add the following to `.cursor/mcp.json` in your application:

```json
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["-y", "shadcn@latest", "mcp"]
    }
  }
}
```

Restart the MCP connection after changing the configuration. Other clients use the same command and arguments in their own MCP configuration format. The [official setup guide](https://ui.shadcn.com/docs/mcp) covers supported clients, including Codex, Claude Code, and VS Code.

The connection runs through local standard input/output. It requires Node.js, npm, and network access to fetch the registry. Follow your client's normal controls when applying files to a project.

## Try it

- Show the registries configured in this project.
- Search `@agents-kit` for thinking, approvals, and generated results.
- Inspect `@agents-kit/agent-generative-surface` and show its files and dependencies.
- Get the install command for `@agents-kit/beui-prompt-input`.

Inspect the returned source and install command before using the component. After installation, complete the shared-style imports in the [installation guide](/docs/installation).

## Check the connection

If the assistant cannot find Agents Kit, check that it is using your application's working directory and that the namespace is present in `components.json`. These public endpoints should be reachable:

- [Registry index](https://agents-ui.github.io/agents-kit/c/registry.json)
- [Generated surface entry](https://agents-ui.github.io/agents-kit/c/agent-generative-surface.json)

If MCP is unavailable, use the CLI directly:

```bash
npx shadcn@latest add https://agents-ui.github.io/agents-kit/c/agent-generative-surface.json
```

MCP makes component source available to a coding assistant. It does not connect your finished application to a model, execute tools for your users, or provide an Agents Kit backend.
