# Agent Inquiry

Pause agent execution to collect user input through multiple choice, text, confirmation, or scale inputs before proceeding with the task.

## Features

- **Multiple Input Types**: Support for multiple choice, text input, confirmation, and scale ratings
- **Agent Context**: Shows why the agent needs input and what it's working on
- **Progress Tracking**: Displays remaining decisions needed before the agent can continue
- **Inquiry History**: Review previously answered questions in the current session
- **Skip Option**: Allow users to skip non-required questions
