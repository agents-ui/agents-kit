# Agent Artifact

Display AI-generated structured artifacts such as code snippets, tables, and documents with live preview and version history.

## Features

- **Multi-Type Support**: Render code blocks, data tables, documents, and other structured outputs
- **Tab Preview**: Switch between rendered preview and raw source in a tabbed interface
- **Version History**: Browse and restore previous versions of the artifact
- **Code Display**: Syntax-highlighted code view with copy-to-clipboard support
- **Export Actions**: Download or share artifacts in multiple formats
