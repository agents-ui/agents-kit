# Introduction

Agents Kit is a React component library for conversations, generated results, and the work around them. Copy the components into your application, pass in your data, and connect the callbacks to your own services.

## What's in v0.2

- Generated results: comparisons, recommendations, documents, checklists, source briefs, audio, focus timers, flights, places, weather, stories, inboxes, notes, collections, events, and activity.
- Conversation and work components: loading, thinking, messages, prompts, approvals, tools, tasks, citations, code, tables, and complete workspaces.
- Runtime controls: thinking orbs, context usage, and checkpoints.
- Optional effects: Border Beam and Gooey.

The [component catalog](/components) groups related implementations into families. Each preview links to its source. The [playground](/generative) shows how results behave in ready, loading, and error states.

## How it fits your application

Components accept props and expose callbacks. Your application owns model calls, streaming, tool execution, file uploads, permissions, and saved data. A loading animation does not run a task, and an approval button does not grant permission by itself.

Agents Kit is distributed as source through a shadcn-compatible registry. It is not a hosted service or an agent runtime. The documentation site uses Next.js; the components are React source that you can integrate with your own build setup.

## v0.1 compatibility

The original component import paths and registry names remain available. Existing users can keep those imports while adopting v0.2 components one at a time. Browse the [v0.1 archive](/v0.1) or read the [migration guide](https://github.com/agents-ui/agents-kit/blob/main/docs/migrating-to-v0.2.md).
