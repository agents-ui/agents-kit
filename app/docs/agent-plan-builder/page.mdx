# Agent Plan Builder

Let AI propose multi-step plans for human review, with dependency tracking, per-step approval, and confidence scoring before execution begins.

## Features

- **Step-by-Step Review**: Each plan step is presented as an inspectable card with description, tools, and estimated duration
- **Dependency Tracking**: Visual dependency graph shows which steps block others and the critical path
- **Per-Step Approval**: Approve, reject, or modify individual steps without discarding the entire plan
- **Confidence Score**: Model confidence displayed per step so reviewers can focus on uncertain areas
- **Global Actions**: Approve all, reject all, or request a full re-plan with a single click
