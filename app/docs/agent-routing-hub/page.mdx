# Agent Routing Hub

Intelligent query routing interface that classifies user intent and dispatches requests to the most suitable specialized agent.

## Features

- **Intent Classification**: Incoming queries are analyzed and tagged with detected intent categories
- **Route Matching**: Visual routing table maps intents to available specialist agents with match scores
- **Agent Selection**: Highlighted selection shows which agent was chosen and why, with fallback options
- **Routing History**: Scrollable log of past routing decisions with latency and outcome data
- **Manual Override**: Users can override the automatic selection and redirect to a different agent
