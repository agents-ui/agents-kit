# Agent Data Analysis

AI-powered dataset analysis that surfaces key metrics, visualizations, and actionable insights from uploaded or connected data sources.

## Features

- **Key Metrics**: Auto-detected summary statistics displayed as prominent metric cards
- **Data Preview**: Paginated table preview of the raw dataset with column type badges
- **AI Insights**: Natural-language findings and anomaly callouts generated by the agent
- **Distribution Charts**: Inline mini-charts showing value distributions for numeric columns
- **Follow-up Actions**: Suggested next steps such as deeper drill-downs, exports, or alerts
