# Fieldwork artwork provenance

These original fictional assets were generated with OpenAI's built-in image generation tool for the Agents Kit generative UI examples. No reference images were used.

- `fieldwork-harbour.webp` — Rain-washed working harbour at blue hour, with teal water, an amber-lit boat cabin, and tactile mooring rope details.
- `fieldwork-studio.webp` — Sunlit design workshop still life with terracotta samples, vellum sketches, and an indigo pencil.
- `fieldwork-botanical.webp` — Dew-covered sculptural fern in a softly lit, condensation-glazed glasshouse.

All prompts specified square editorial photography with no people, readable text, logos, brands, recognizable landmarks, or copied social-media compositions.
